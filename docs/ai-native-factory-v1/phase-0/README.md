# Phase 0 Sample Freeze Kit

Phase 0 freezes the first practical sample before software, process, and hardware teams start building against moving assumptions.

Use this kit to run the first working session:

1. `01-first-order-sample-freeze.md`
2. `02-validation-machine-freeze.md`
3. `03-resource-master-data-freeze.md`
4. `04-offline-chain-runbook.md`

Expected outputs:

- One frozen historical order and part sample.
- One validation machine candidate with interface and sensing readiness.
- Minimum resource master data for the first OEP.
- One offline chain result: quote draft, process draft, and OEP draft.
- Evidence list for gaps that must be closed before Phase 1 controlled physical execution.

Do not start Phase 1 execution until required sensing organs, OEP gates, human approvals, and command trace rules are ready.
